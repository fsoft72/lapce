## Installation With Package Manager

GoldenIDE is available in below software repositories:

[![Packaging status](https://repology.org/badge/vertical-allrepos/goldenide.svg)](https://repology.org/project/goldenide/versions)

GoldenIDE is also additionally available via:

- [Flatpak](https://flathub.org/apps/details/dev.goldenide.goldenide)
- [Scoop](https://scoop.sh/#/apps?q=goldenide)


For Fedora Linux, GoldenIDE is (unofficially) available via dnf RPM package manager, using nightly as of 2024.01:

- [copr](https://copr.fedorainfracloud.org/coprs/titaniumtown/goldenide/)

```bash
sudo dnf copr enable titaniumtown/goldenide 
sudo dnf install goldenide
```
